# DirectorCut 0.3 — Integrated test guide

## Update and run (Windows)

```powershell
git checkout main11
git pull origin main11
.\scripts\setup-windows.ps1
.\scripts\run-windows.ps1
```

For local Whisper transcription:

```powershell
.\scripts\setup-windows.ps1 -InstallAI
```

Ollama does not need to be installed by DirectorCut. When the app starts it checks the local Ollama service, reads `/api/tags`, lists your installed models, and lets you select one. Selecting a model warms it so the first real conversation is faster.

## Manual and Director share one timeline

1. Load a video.
2. Leave the top toggle on **Manual**.
3. Talk normally in the floating bottom composer. The assistant may explain or analyze but must not create timeline operations.
4. Drag the video clip with Select, Ripple, Slip, Slide, and Roll tools.
5. Switch the top toggle to **Director**.
6. Select **Co-edit** and ask `split here` or set In/Out and ask `remove this range`.
7. The change should appear as a proposal. Apply or reject it.
8. Select **Auto** and repeat an editing instruction. Only validated typed operations are allowed to mutate the timeline.
9. Switch back to Manual and keep hand-editing the same timeline.

## Ollama

- Ollama is discovered automatically at `127.0.0.1:11434`.
- Installed models appear in both model selectors.
- The selected model is remembered.
- Selecting a model warms it for 15 minutes.
- Normal conversation is classified separately from edit tasks.
- Manual mode never accepts AI timeline operations.

If Ollama is installed but not running, start the Ollama application or run `ollama serve`, then press refresh in DirectorCut.

## Media cache and speed

1. Load a video and start editing immediately.
2. Thumbnails and the audio waveform build without blocking the renderer.
3. Press **Build proxy** for heavy 4K/HEVC footage.
4. Enable **Use proxy** after generation. Export continues to use the original source.

## Frame-level editing

- In/Out points, split markers, clip moves and keyframes are snapped to the source frame rate.
- `Delete In→Out` performs a ripple delete in the timeline.
- Export uses decode-accurate seeking rather than keyframe-only input seeking.

## Professional timeline primitives

The v0.3 timeline model includes multiple video/audio/caption/graphics tracks, draggable clips, snapping, ripple moves/deletes, roll boundary edits, slip edits, slide edits, keyframe storage/display, undo snapshots, and autosave every 12 seconds after changes.

Current limitation: multi-source compositing/export and rendered keyframe effects are not finished yet. The project model already stores the information needed for those next steps.

## GStreamer status

DirectorCut now contains two GStreamer pieces:

1. Desktop capability detection for GStreamer, GES and GPU plugin families (D3D11/12, Vulkan, NVCodec, QSV, VAAPI, AMF, VideoToolbox).
2. An optional native C++ `directorcut_gstreamer` target using GStreamer `playbin3`/`playbin` with accurate seeking.

The Electron monitor still uses Chromium video playback in 0.3. The native GStreamer target is the backend scaffold for the next embedded-preview integration; do not interpret the GStreamer status line as meaning the Electron monitor is already rendering through GStreamer.

For Windows native development, install the current official 64-bit MSVC GStreamer runtime + development components. CMake automatically enables the native target when `pkg-config` can resolve `gstreamer-1.0`; if GStreamer Editing Services is also found it defines `DIRECTORCUT_HAS_GES` for the upcoming timeline bridge.

## What to report from your PC

If something fails, send a screenshot plus the terminal output from `run-windows.ps1`. The most useful hardware details are GPU model, the GStreamer status shown in the app, the Ollama model selected, and whether the footage is H.264, HEVC, AV1 or another codec.
